# Code of Conduct

## <a href="#our-pledge"><img src="https://svg.xul.is/icon/heart-handshake?size=32&stroke=2" align="left" /></a>Our Pledge

We pledge to make participation in the Python library [**`xulbux`**](https://xulbux.github.io/python-lib-xulbux) a welcoming, harassment-free experience for everyone, regardless of background, identity, or experience level.

<br>

## <a href="#our-standards"><img src="https://svg.xul.is/icon/users?size=32&stroke=2" align="left" /></a>Our Standards

-   **Expected Behavior:** Be respectful and constructive in reviews and discussions, focus on technical merit and what is best for the community, and accept feedback gracefully.
-   **Unacceptable Behavior:** Harassment, personal attacks, trolling, discriminatory or sexualized language, publishing private information without consent, or other conduct inappropriate in a professional open-source setting.

<br>

## <a href="#enforcement"><img src="https://svg.xul.is/icon/scale?size=32&stroke=2" align="left" /></a>Enforcement

Project maintainers may edit, remove, or close comments, issues, commits, or pull requests that violate this Code of Conduct, and may temporarily or permanently ban contributors for severe or repeated behavior.

Report unacceptable behavior confidentially to [hi@xul.is](mailto:hi@xul.is). Adapted from the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
